رشدآموز — پروژه آزمایشی اندروید (WebView)

این بسته، سورس یک پروژه Android Studio است و خودش فایل APK کامپایل‌شده نیست.
در این محیط Android SDK/Gradle برای ساخت APK موجود نبود؛ بنابراین ادعای ساخت APK نهایی نمی‌کنیم.

ساخت APK:
1) Android Studio را روی کامپیوتر نصب کن.
2) این پوشه را از File > Open باز کن.
3) اگر درخواست شد، Gradle و Android SDK را نصب/همگام‌سازی کن (Compile SDK 35).
4) از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کن.
5) فایل خروجی معمولاً در app/build/outputs/apk/debug/app-debug.apk قرار می‌گیرد.

ورود آزمایشی: admin

محدودیت‌های مهم:
- این فقط نمونه اولیه آفلاین است؛ ورود admin امنیت واقعی ندارد.
- داده‌ها در حافظه صفحه هستند و با بستن/بازکردن برنامه ممکن است پاک شوند.
- پنل مستقل امن دانش‌آموز و والدین، پایگاه داده، همگام‌سازی ابری و بازیابی رمز هنوز پیاده‌سازی نشده‌اند.
- امتیازهای اولیه ۲۰ دانش‌آموز تا زمان ذخیره ارزیابی معیارها به‌صورت مجموع مستقل حفظ می‌شوند.
- برای استفاده واقعی از داده‌های افراد، ابتدا احراز هویت امن و ذخیره‌سازی مناسب لازم است.
